# 중요 포인트 (꼭 읽을 것)

인계 문서 중에서 **놓치면 문제가 되는 것만** 따로 모았다.

## 🔴 보안·비용 (실수하면 되돌리기 어려움)
1. **비밀 값은 커밋 금지**: `.env`, `google-services.json`, `serviceAccount*.json`, 카카오 REST 키·클라이언트 시크릿, DART 키. `.gitignore`에 들어 있지만, 새 파일을 만들 때마다 확인한다. GitHub 웹 화면의 `.env.example`에는 **값을 적지 않는다**(빈 양식 파일).
2. **서비스 계정 JSON은 가장 위험한 값**: Firestore 보안 규칙을 우회한다. GitHub Secrets(`FIREBASE_SERVICE_ACCOUNT`)와 로컬 환경 변수로만 쓰고, 채팅·이슈·로그에 붙이지 않는다.
3. **Spark(무료) 플랜 유지**: Cloud Functions, Cloud Storage는 카드 등록(Blaze)이 필요하다. 이를 쓰는 기능을 추가하지 않는다. (알림은 GitHub Actions, 첨부는 없음)
4. **Firestore 보안 규칙을 배포해야 접근이 열린다**. 그리고 규칙은 **아직 실제로 검증하지 못했다.** 배포 후 콘솔 "규칙 플레이그라운드"에서 ① 가족 이메일 → 읽기 허용, ② 다른 이메일 → 거부, ③ `kakaoTokens` 접근 거부를 직접 확인할 것.

## 🟠 동작에 영향을 주는 함정
5. **`EXPO_PUBLIC_*`는 `process.env.EXPO_PUBLIC_NAME`으로 직접 참조**해야 빌드 때 값이 들어간다. `const env = process.env; env.X` 같은 코드는 값이 비게 된다. (`src/firebase/config.ts` 참고)
6. **Android의 Google 로그인은 Expo Go에서 안 된다**(네이티브 모듈). 개발 빌드(EAS 또는 로컬 Android SDK)가 필요하다. → **웹으로 먼저 검증**하고 Android는 나중에.
7. **Firebase 설정이 비어 있으면** 앱은 "설정이 필요해요" 화면을 보여 준다. 이 화면이 보이면 `.env`가 비었거나 서버를 재시작하지 않은 것이다(`.env`를 고치면 `npm run web`을 다시 실행).
8. **가족은 최대 4명**(규칙 `validMembers`). 5번째 이메일 추가는 거부된다. 이메일은 소문자로 저장·비교한다.
9. **카카오 "나에게 보내기"는 앱 팀원만 심사 없이 사용 가능**하다. 가족 4명을 카카오 개발자 앱의 멤버로 초대해야 한다. 리프레시 토큰은 약 2개월 뒤 만료되며, 알림이 계속 가면 자동 갱신된다. 오래 끊기면 `npm run kakao:login`을 다시 한다.
10. **GitHub Actions 스케줄**: 몇 분~수십 분 지연될 수 있고, 저장소에 60일간 활동이 없으면 자동 중지된다. cron은 UTC(KST−9시간)다. 알림 슬롯은 `notify.yml`의 cron 문자열로 결정되므로, cron을 바꾸면 "슬롯 결정" 단계의 `case` 문도 같이 바꾼다.
11. **종목 저장 방식**: 저장하면 수집값(`collected`)과 다른 필드만 `manual`에 들어간다(`manual`은 통째로 교체). 수집값과 같은 필드는 manual에서 빠져서 이후 DART 갱신이 계속 반영된다.

## 🟡 검증되지 않은 가정 (실제로 확인할 것)
12. **DART**: 공시상세유형 `C001`(증권신고서·지분증권), "상장 전 법인은 `corp_cls=E`"는 **실제 응답으로 확인하지 못했다.** `collect-dart.yml`을 `dry_run`으로 돌려 로그로 확인한다. DART는 종목 이름·유형만 채우고 청약일·공모가·주관사는 수동 입력이다.
13. **플래너의 가정**: 증거금 묶임 구간은 `[청약 마감일, 환불일)`(환불일 당일 재사용 가능), 청약 수수료는 배정 수량 > 0일 때만 부과, 증거금 = 공모가 × 최소 청약 주수 × 증거금률. 증권사마다 다를 수 있으니 **실제 공지로 증권사 설정을 채워야** 한다(기본값은 10주 / 50% / 수수료 0원).
14. **실제 화면 동작은 아직 한 번도 돌려 보지 못했다**(Firebase 없이 번들 빌드와 로직 테스트까지만). 첫 실행에서 버그가 나올 수 있으니 오류 메시지를 그대로 가져와서 고친다.
15. 클라우드 환경에서는 `docs.expo.dev`와 Expo API가 막혀 있었다. Expo SDK 58 API는 설치된 타입 정의로 확인했다. 로컬에서는 공식 문서를 참고해도 된다.

## 🟢 제품 원칙 (바꾸지 말 것)
16. **개인·가족용**: 공개 배포, 제휴, 광고, 커뮤니티 없음. 공개하게 되면 투자자문업 해당 여부와 DART 약관을 먼저 재검토한다.
17. **투자 권유 표현 금지**: 앱의 계산(증거금, 수수료, 순수익)은 참고용이다. "이 종목 사라" 같은 문구를 넣지 않는다. 설정 화면의 면책 문구를 유지한다.
18. **저장하지 않는 것**: 계좌번호, 증권사 비밀번호, 실제 잔고.
19. **사용자 응대**: 한국어, 한 번에 한 단계, 복사 가능한 명령어, Firebase 한글 콘솔 메뉴 이름 그대로. 키는 채팅에 붙이지 않게 안내.

## 📅 일정 압박
20. **목표: 11월 말 청약부터 실사용.** 최소 경로는 `Google 로그인 설정 → Firestore → .env → 규칙 배포 → 웹 실행 → 가족 이메일 추가 → 증권사 설정 → 종목 1개 리허설`이다. 카카오 알림은 그 뒤에 붙여도 앱 자체는 쓸 수 있다.
